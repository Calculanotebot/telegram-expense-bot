# Expense Bot — блокнот + калькулятор расходов

Телеграм-бот: пишешь сообщение с суммой (можно арифметическим выражением) и
комментарием — бот считает и записывает. Хранит всё в SQLite, умеет отчёты
за день/неделю/месяц, топ категорий, удаление и экспорт в CSV.

## Как запустить

### 1. Получить токен бота

1. Напиши в Telegram боту [@BotFather](https://t.me/BotFather)
2. Команда `/newbot`, следуй инструкциям
3. Скопируй токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`

### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

### 3. Указать токен

Либо переменной окружения:

```bash
set TELEGRAM_BOT_TOKEN=твой_токен
```

(в PowerShell: `$env:TELEGRAM_BOT_TOKEN = "твой_токен"`)

Либо создай файл `token.txt` рядом с `bot.py` и вставь туда токен одной строкой.

### 4. Запустить

```bash
python bot.py
```

Бот работает через polling — держи процесс запущенным (терминал, screen/tmux
на сервере, systemd-сервис и т.п.).

## Как пользоваться

Напиши боту в Telegram:

```
250 кофе
100+50+30 продукты
125.50 такси домой
-100 возврат
```

Первое число (или арифметическое выражение) — сумма, всё после — категория/
комментарий. Если комментарий не написан, запись попадёт в «Без категории».

Команды:

- `/today` — расходы за сегодня
- `/week` — расходы за 7 дней
- `/month` — расходы за текущий месяц по категориям
- `/stats` — топ категорий за всё время
- `/last [N]` — последние N записей (по умолчанию 10)
- `/undo` — удалить последнюю запись
- `/delete <id>` — удалить запись по номеру
- `/export` — выгрузить все записи в CSV
- `/clear confirm` — удалить вообще все свои записи

Данные у каждого пользователя бота свои (разделены по user_id), так что
бота можно смело шарить с другими людьми — они не увидят чужие траты.

## Данные

Хранятся в `expenses.db` (SQLite) рядом с `bot.py`. Путь можно переопределить
переменной окружения `EXPENSE_BOT_DB`.
